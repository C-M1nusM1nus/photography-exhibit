# 📷 Photography Exhibit
A simple photography gallery webpage showcasing a small collection of photographs featuring architecture, mountains, and open water.

The project uses HTML and Tailwind CSS to create a clean, responsive, and modern gallery layout.

# Features
* Photography exhibit-style layout
* Three featured photographs
* Image titles and descriptions
* Responsive three-column grid on larger screens
* Single-column layout on smaller screens
* Clean and minimal design
* Uses Tailwind CSS utility classes for styling

# Featured Photos
## Echoes of Rome
A photograph of the Colosseum in Rome, highlighting its historic architecture and atmosphere.

## Above the Clouds
A photograph of the Alps, featuring snow-covered mountain peaks and open skies.

## Open Water
A photograph of the sea, focusing on the horizon and the calmness of open water.

# How It Works
The page uses a responsive CSS grid to organize the photographs.
* On small screens, the photos appear in a single column.
* On medium and larger screens, the photos are displayed in three columns.
Each photograph is contained inside an **<article>** element with an image, heading, and description.
